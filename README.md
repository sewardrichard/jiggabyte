# Jiggabyte Technology Limited

![Jiggabyte Logo](assets/logo_light.svg)

Empowering innovation through intelligent technology. Jiggabyte Technology Limited is a forward-thinking technology company based in Lusaka, Zambia, building the next generation of AI solutions, automation systems, intelligent assistants, and custom software.

## 🚀 Vision

To lead modern African technology leadership by building structured, intelligent modules that solve real-world problems. We envision a future where local businesses operate with global efficiency.

## ✨ Features

- **Innovation Through Intelligent Technology**: Modern, high-performance web presence using cutting-edge design principles.
- **AI-Powered Solutions**: Custom AI agents engineered to integrate seamlessly into existing infrastructure.
- **Automation Design**: Robust, scalable automation systems built for precision.
- **Responsive Design**: Fully optimized for all devices, from mobile to desktop.
- **Premium Aesthetics**: Featuring glassmorphism, dynamic gradients, and modern typography (Syne & DM Sans).

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Icons**: [Lucide Icons](https://lucide.dev/)
- **Typography**: [Google Fonts](https://fonts.google.com/) (Syne, DM Sans)
- **Design Patterns**: Glassmorphism, Responsive Grid Systems, CSS Variables

## 📁 Project Structure

- `index.html`: Main landing page structure.
- `styles.css`: Core styling and design system.
- `script.js`: Interactive elements, scroll animations, and mobile menu logic.
- `assets/`: 
    - `logo_light.svg` / `logo_dark.svg`: Brand identity.
    - `favicon.svg`: Site icon.
    - `images/`: Project screenshots and testimonial avatars.
- `coming_soon_page/`: A dedicated pre-launch landing page.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/sewardrichard/jiggabyte.git
   ```
2. Open `index.html` in any modern web browser.
